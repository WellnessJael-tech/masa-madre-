# SEO — Masa Madre

## Principios
- Cada página de producto necesita title y meta description únicos
- Uso correcto de encabezados (H1 único por página, jerarquía lógica)
- URLs limpias y descriptivas (ej: /producto/nombre-del-producto)
- Imágenes optimizadas y con alt descriptivo (también ayuda accesibilidad)

## Checklist
- ¿Cada producto tiene su propia URL amigable?
- ¿Hay un solo H1 por página?
- ¿Las imágenes están comprimidas?
