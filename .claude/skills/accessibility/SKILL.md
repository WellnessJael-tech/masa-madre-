# Accesibilidad — Masa Madre

## Principios
- Contraste mínimo AA (4.5:1 para texto normal)
- Todo elemento interactivo debe ser accesible por teclado (Tab, Enter)
- Imágenes con texto alternativo (alt) descriptivo
- Formularios con etiquetas (labels) claras, no solo placeholders

## Checklist
- ¿Se puede navegar todo el sitio solo con teclado?
- ¿Los botones tienen texto o aria-label descriptivo?
- ¿El contraste de texto es legible?
