# UI/UX — Masa Madre

## Principios
- Mobile-first siempre
- Consistencia visual entre core y theme
- Jerarquía visual clara: el usuario debe entender qué hacer sin pensar

## Checklist al crear un componente
- ¿Es reutilizable entre distintos themes?
- ¿Tiene estados claros (hover, activo, disabled, error)?
- ¿Es accesible por teclado?
- ¿El flujo de compra tiene la menor fricción posible?
