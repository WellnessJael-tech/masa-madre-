# Responsive Design — Masa Madre

## Principios
- Mobile-first: se diseña primero para pantallas pequeñas, luego se escala
- Breakpoints sugeridos: 375px (móvil), 768px (tablet), 1280px (escritorio)
- Ningún componente debe romperse o generar scroll horizontal en móvil

## Checklist
- ¿Se probó en 375px de ancho?
- ¿Las imágenes se adaptan sin distorsionarse?
- ¿Los botones son suficientemente grandes para tocar en móvil (mínimo 44x44px)?
